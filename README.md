# LINE Group Errand App (LINE LIFF & AI Vision)

หน้าเว็บ LIFF แนวขาวคลีนสำหรับระบบฝากซื้อของในกลุ่ม LINE (เช็กของหน้าร้านแบบติ๊กขวามือ, ปุ่มดูรูปสินค้า, หาร VAT/Service Charge, รายละเอียดบิลรายบุคคล และเช็กสถานะการโอน)

## วิธีนำขึ้น GitHub Pages (ฟรี 100%)
1. แตกไฟล์ ZIP นี้ จะได้ไฟล์ `index.html`, `README.md` และ `.nojekyll`
2. สร้าง Repository ใหม่บน GitHub (ตั้งค่าเป็น **Public**)
3. อัปโหลดไฟล์ทั้งหมดขึ้นไปที่ Root ของ Repository แล้วกด **Commit changes**
4. ไปที่ **Settings** > **Pages** > เลือก **Deploy from a branch** > **main** / **/(root)** แล้วกด **Save**
5. นำ URL ที่ได้ (เช่น `https://username.github.io/line-errand-liff/`) ไปใส่ใน **Endpoint URL** บน LINE Developers (แท็บ LIFF ของ LINE Login Channel)
6. นำ **LIFF ID** ที่ได้มาแก้ไขใส่แทนคำว่า `YOUR_LIFF_ID_HERE` ในไฟล์ `index.html`
